## 未发布 [#unreleased]

- 本地化：每次构建都会按源文件为翻译工具写出提取清单（`Intermediate/DLoc/extract/DreamNarrative/`），包含每条文本的 key、原文、位置、类别、稳定性、`was` 改名与上下文；`///` 注释是给译者的备注。
- 任务目标文本、资料库条目和演出文本都可以写 `#id`，`dnc freeze` 也会为它们写入。
- 没有显示名或标题的角色、任务、资料库和章节，会翻译其名称本身。
- DNS6007：同一文件中的两条文本使用了同一个 key。
- 已移除 `dnc loc-export` / `loc-import`：DreamLoc 按清单翻译，并导入其 CSV。
- 其他语言的配音是引擎在 `Content/L10N/<culture>/` 下的本地化资产。

## 0.1.0 [#010]

首个公开版本：

- 语言：fact 与作用域、对话、频道与事件、任务、章节与周目、资料库、演出，以及 `test` / `explore` 块，并附有带解释的诊断参考。
- 运行时：账本、对话 runner、任务、章节、事务化演出导演与看门狗、GAS 双向桥与能力任务。
- 编辑器：可写回源码的故事视图、调试器、演出时间轴、对话演出生成器、关卡序列导入、DreamGameplayTask 迁移以及保存时重建。
- 工具：`dnc`、测试宿主与四档测试预设、探索器、录制/回放以及 VS Code 扩展。
