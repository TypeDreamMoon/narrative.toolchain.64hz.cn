---
title: "表达式"
description: "条件和插值中支持的表达式。"
---

| 写法 | 含义 |
| --- | --- |
| `and`, `or`, `not` | 逻辑 |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | 比较；tag 只支持判等，不支持排序 |
| `+`, `-`, `*`, `/`, `%` | 算术 |
| `心情 in (平静, 不安)` | tag 属于集合 |
| `chapter == 风暴` | 当前章节 |
| `visited(老周_初见)` | 离开这段对话的次数 |
| `random(1, 6)`, `chance(0.3)` | 带种子、可回放的随机 |
| `修灯.active`, `修灯.completed`, `修灯.failed`, `修灯.available` | 任务状态 |
| `风暴逼近.等级` | 打开这段对话的事件的参数 |

没有字符串，也没有三元运算符。类型在编译期检查（[DNS4xxx](/docs/diagnostics/dns4xxx)）。这里的中文名称是合法的示例标识符。
