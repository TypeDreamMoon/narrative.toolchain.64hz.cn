---
title: "表达式"
description: "条件与插值里能写什么。"
---

| 写法 | 意思 |
|---|---|
| `and`、`or`、`not` | 逻辑 |
| `==`、`!=`、`<`、`<=`、`>`、`>=` | 比较(tag 只能判等) |
| `+`、`-`、`*`、`/`、`%` | 算术 |
| `心情 in (平静, 不安)` | tag 属于集合 |
| `chapter == 风暴` | 当前章节 |
| `visited(老周_初见)` | 离开过这段对话几次 |
| `random(1, 6)`、`chance(0.3)` | 随机(带种子,可回放) |
| `修灯.active`、`修灯.completed`、`修灯.failed`、`修灯.available` | 任务状态 |
| `风暴逼近.等级` | 打开这段对话的事件的参数 |

没有字符串,没有三元。类型在编译期检查(DNS4xxx)。
