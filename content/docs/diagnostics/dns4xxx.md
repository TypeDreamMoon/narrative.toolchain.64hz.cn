## DNS4001 [#dns4001]

类型不匹配。

**解释：** 例如把数字赋给 bool、拿 bool 与数字比较大小、对非数字使用 `+=`，或者把非条件传给 `and`。消息会说明涉及的类型。fact 只有 `bool`、`int`、`float` 和 `tag` 四种类型；请对照声明检查表达式。

## DNS4002 [#dns4002]

tag 值超出其声明的集合。

**解释：** tag fact 用 `in (甲, 乙, 丙)` 声明允许的成员。赋值、比较和成员列表只能使用这些值。请改正拼写错误，或把想要的成员加入集合。声明 tag fact 或事件参数时没有提供集合也会触发此代码。

## DNS4003 [#dns4003]

常量超出声明的范围。

**解释：** 给声明为 `range 0..10` 的 fact 赋 99 是可在静态检查中发现的错误。运行时写入会被钳制到范围内，但源码中越界的常量应当改正。

## DNS4004 [#dns4004]

这些值无法比较大小。

**解释：** `<`、`<=`、`>` 和 `>=` 只适用于数字。tag 和 bool 没有顺序。要检查状态是否已达到某个特定值，请使用 `==` 或 `in (...)`。

## DNS4005 [#dns4005]

内置函数的使用方式有误。

**解释：** 内置函数只有 `visited(Dialogue)`、`random(Minimum, Maximum)` 和 `chance(Probability)`。参数个数或类型不对，以及使用未知的函数名，都会触发此代码。任务状态使用 `Quest.completed` 这样的属性，而不是函数调用。

## DNS4006 [#dns4006]

此处要求常量。

**解释：** fact 默认值、事件参数默认值以及章节 `implied` 的值会在编译期求值并存入资产。它们不能依赖 fact、章节或随机性。请使用字面量或集合成员。

## DNS4007 [#dns4007]

gameplay 来源与目标类型不匹配。

**解释：** 由标签驱动的 fact 可以是 bool（表示标签是否存在）或 int（表示标签数量）。`from magnitude` 提供一个数字，支持 int 或 float。`from instigator tags` / `from target tags` 支持 bool（表示是否存在）或 tag（取指定标签下面那一段）：对于 `敌人.体型.大型`，该段是 `大型`，它必须属于参数的集合。请更改目标类型或来源。
