由 `scripts/gen-diagnostics.mjs` 从插件的 `Docs/Diagnostics.md` 生成。

## DNS4001 [#dns4001]

类型不匹配。

给 bool fact 赋数字、拿 bool 和数字比大小、对非数字用 `+=`、`and` 两边不是条件……凡是值的种类对不上都报这个码。消息里会说明两边各是什么。fact 只有四种类型:bool、int、float、tag;写表达式时对照声明看一眼。

## DNS4002 [#dns4002]

tag 值不在 fact 声明的集合里。

tag fact 用 `in (甲, 乙, 丙)` 声明它能取的值,之后赋值、比较、`in` 列表里只能用这几个。写了集合外的名字,通常是拼写错误或者忘了往集合里加新值。声明了 tag 类型却没写集合(fact 或事件参数),也报这个码。

## DNS4003 [#dns4003]

常量超出了 fact 声明的范围。

`range 0..10` 的 fact 直接赋 99 是明显的错误,编译期就能抓住。运行时的写入会被钳到范围内,但源码里写死的越界值应该改掉。

## DNS4004 [#dns4004]

这两种值没有大小可比。

`<`、`<=`、`>`、`>=` 只对数字有意义。tag 之间没有顺序,bool 也没有。想表达"状态到了某一步",用 `==` 或 `in (...)`。

## DNS4005 [#dns4005]

内置函数用错了。

内置只有三个:`visited(对话)`、`random(最小, 最大)`、`chance(概率)`。参数个数或种类不对、或者调用了不存在的函数名,都报这个码。任务状态用 `任务.completed` 这类属性写法,不是函数。

## DNS4006 [#dns4006]

这里必须是常量。

fact 与事件参数的默认值、章节 `implied` 里的值要在编译期算出来存进资产,不能引用其他 fact、章节或随机数。换成字面量或集合成员。

## DNS4007 [#dns4007]

gameplay 来源和类型对不上。

标签喂 fact 时,bool 表示「有没有这个标签」,int 表示「有几层」,别的类型没有对应的意思。参数的 `from magnitude` 是一个数,只能给 int 或 float 参数;`from instigator tags` / `from target tags` 只能给 bool 参数(有没有这个标签)或 tag 参数(取这个标签下面那一层的末段,比如 `敌人.体型.大型` 取 `大型`,要在参数的集合里)。改参数类型,或者换一种来源。
